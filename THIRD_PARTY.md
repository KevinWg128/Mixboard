# Data sources

The dictionary files in `app/src/main/assets/` are generated by `tools/build_dict.py` from:

| Data | Used for | Licence |
|---|---|---|
| [rime-cangjie](https://github.com/rime/rime-cangjie) `cangjie5.base.dict.yaml` | 倉頡 codes → 速成 codes | GPL |
| [rime-essay](https://github.com/rime/rime-essay) `essay.txt` | character and word frequency | LGPL-3.0 |
| [rime-cantonese](https://github.com/rime/rime-cantonese) `jyut6ping3.words.dict.yaml` | Cantonese vocabulary for 聯想 | CC BY 4.0 |
| [HKCanCor](https://github.com/fcbond/hkcancor) via [PyCantonese](https://pycantonese.org) | spoken HK word frequency | CC BY 4.0 |
| [ECDICT](https://github.com/skywind3000/ECDICT) `ecdict.csv` | English → Chinese | MIT |
| [OpenCC](https://github.com/BYVoid/OpenCC) | Simplified → HK Traditional | Apache-2.0 |

This app is built for personal use and not distributed.
